La définition du HTML

La structure d'un document

                    <!DOCTYPE html>
<html lang="fr">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

La déclaration du type

                    <!DOCTYPE html>

La déclaration !DOCTYPE n'est pas une balise HTML

Il s'agit d'une instruction donnée au navigateur et aux outils de vérification syntaxique sur la version du langage HTML.

Anatomie d'un élément HTML

<p class= "classeCSS" > Jhon Doe </p>

  1. La balise ouvrante
  2. Un attribut constitué
    1. D'un nom
    2. D'une valeur
  3. Le contenu
  4. La balise fermante
