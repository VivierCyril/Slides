Permet à la fois de développer :

  • Des site Web
  • Des serveurs
  • Des application mobile
  • Des application desktop
  • Du machine learning
  • Des math avancées
  • De la visualisation de données
  • Du Natural Language Processing (NLP) et des chatbots
